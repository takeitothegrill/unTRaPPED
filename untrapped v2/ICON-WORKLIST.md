# Icon worklist — working copy

https://www.google.com/maps/d/edit?mid=1GsgVncG-IYRalSk_u7ZmuDQluhPQmpQ

Derived from each pin's own name on the map — EXCELLENT/GOOD = green,
OKAY/STANDARD = orange, everything else = red (per the agreed rule:
when in doubt, go lower; when undecidable, red).
**85 pins, 11 distinct icons.**


**Work one ICON at a time, not one pin at a time.** First use of an icon goes
through the picker (paint-can -> More icons -> Custom icon -> Photos -> search
`untrapped-icons`). Every use after that it sits under **Other icons** in the
paint-can: hover pin -> paint-can -> click icon. Two clicks.
